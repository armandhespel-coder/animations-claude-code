# 20 animations vidéo à faire avec Claude Code

Aucun logiciel de montage. Tu décris l'animation, Claude Code l'écrit en HTML et la rend en vidéo avec **HyperFrames** (open source, gratuit).

## 1. Installer (une seule fois)

Dans un terminal :

```bash
claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes
```

Ensuite, ouvre Claude Code, glisse ta vidéo dans le dossier et **copie la phrase de la colonne « À dire à Claude »**.
